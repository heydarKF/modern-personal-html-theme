۰۳

معماری قالب

سه لایه، عمداً ساده تا نگهداری‌اش راحت بماند:

  1. global.css — هرچیز بین صفحات مشترک: توکن‌ها + کامپوننت‌ها + هدر/فوتر.
  2. <style> داخل هر صفحه — CSS اختصاصی همان صفحه، با پیشوند معنایی.
  3. <script> داخل هر صفحه — یک IIFE شامل «بخش مشترک» (تم/هدر/منو/lang/reveal/year) + «بخش صفحه».

قواعد طلایی

  • به global.css فقط چیزِ واقعاً مشترک اضافه کنید؛ وگرنه همهٔ صفحات باد می‌کنند.
  • بلوک مشترک JS عمداً در هر صفحه تکرار شده تا هر فایل self-contained بماند.
  • داخل .mock و .cv هیچ id نگذارید — این nodeها clone می‌شوند (مودال پروژه، preview بلاگ، کاور پست) و id تکراری می‌سازند.
  • هر المانِ دارای data-slug باید ورودی متناظر در دادهٔ همان صفحه داشته باشد.

تغییر رنگ برند (Rebrand)

سریع‌ترین راه: استودیو را تنظیم کنید و «کپی CSS» بزنید؛ خروجی را جای‌گزین بلوک توکن‌های global.css کنید.

:root {
  --accent: #009966;        /* رنگ اصلی */
  --accent-strong: #00b377;  /* hover */
  --accent-deep: #007a52;    /* گرادیانت */
  --accent-ink: #007a52;     /* متن ریز — کنتراست */
  --accent-soft: rgba(0,153,102,.10);
  --accent-line: rgba(0,153,102,.28);
  --on-accent: #052018;      /* متن روی دکمه */
  --shadow-accent: 0 10px 28px -8px rgba(0,153,102,.35);
  --glow-a: rgba(0,153,102,.10);
}
[data-theme="dark"] {
  --accent-ink: #3ecf9a;
  --accent-soft: rgba(0,201,138,.12);
  --accent-line: rgba(0,201,138,.30);
}

رنگ‌های hard-code شده: صحنه‌های ترمینال و کاورها رنگ ثابت دارند (#0d1512, #3ecf9a, #d8b56a, #2b7f8c, #4f83c2, #d64550). برای rebrand کامل این‌ها را در CSS اختصاصی صفحات جست‌وجو و جای‌گزین کنید.

۰۶

هدر، فوتر و منوی موبایل

مارک‌آپ هدر/فوتر در همهٔ صفحات یکسان است. فقط aria-current="page" روی لینک صفحهٔ جاری جابه‌جا می‌شود.

<nav class="main-nav" aria-label="Primary">
  <a href="index.html">Home</a>
  <a href="about.html" aria-current="page">About</a>
  <!-- … -->
</nav>

افزودن یک آیتم ناوبری

  1. در همهٔ صفحات به .main-nav اضافه کنید.
  2. به .mobile-nav با شمارهٔ .idx اضافه کنید.
  3. به .footer-links اضافه کنید.
  4. در صفحهٔ جدید aria-current="page" بگذارید.

هدر شناور است: با اسکرول کلاس .is-scrolled می‌گیرد، جمع‌وجورتر و مات می‌شود. ارتفاع آفست با --header-offset تنظیم می‌شود و scroll-padding-top سراسری، پرشِ anchorها را زیر هدر می‌نشاند.

۰۷

سیستم تم

تم روی <html data-theme="light|dark"> می‌نشیند. اسکریپت کوچکِ داخل <head> قبل از رندر اجرا می‌شود تا پرش رنگ (FOUC) نداشته باشیم.

<script>
(function(){
  var d = document.documentElement;
  d.classList.add('js');
  try {
    var t = localStorage.getItem('hkf-theme');
    if (!t) t = matchMedia('(prefers-color-scheme: dark)').matches ? 'dark' : 'light';
    d.setAttribute('data-theme', t);
  } catch(e){}
})();
</script>
  • ترجیح کاربر در localStorage['hkf-theme'] ذخیره می‌شود.
  • پیش‌فرض از prefers-color-scheme سیستم گرفته می‌شود.
  • سوییچ با View Transitions API کراس‌فید نرم دارد؛ در مرورگرهای قدیمی به ترنزیشن CSS برمی‌گردد.
  • کلاس .js روی html باعث می‌شود بدون JS، محتوا نامرئی نماند.
// به‌جای خواندن سیستم:
var t = localStorage.getItem('hkf-theme') || 'dark';

خاموش‌کردن سراسری

قالب به prefers-reduced-motion احترام می‌گذارد. برای خاموش‌کردن دستی، در استودیو حالت off را انتخاب کنید یا:

@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: .01ms !important;
    transition-duration: .01ms !important;
  }
}

مارکی برای لوپ بی‌درز به دو گروه یکسان نیاز دارد (.marquee-group دوبار، دومی aria-hidden). اگر یکی را حذف کنید، پرش می‌بینید.

۰۹

راهنمای صفحه‌به‌صفحه

index.html — خانه

  • متن هیرو، چیپ‌ها و دکمه‌ها مستقیم در HTML.
  • خطوط ترمینال: .t-cmd و .t-out — متن نهایی را همان‌جا بنویسید؛ JS آن را برمی‌دارد و تایپ می‌کند.
  • آمار: data-target روی .stat-value.
  • کارت‌های پروژه: href="projects.html#slug" — دیپ‌لینک، مودال را باز می‌کند.

about.html — درباره

  • پرتره انتزاعی است. برای عکس واقعی، داخل .portrait یک <img> بگذارید و object-fit:cover; width:100%; height:100% بدهید؛ فریم و seal دست‌نخورده می‌مانند.
  • تایم‌لاین: هر .tl-item یک ایست؛ خط پُر شونده با اسکرول محاسبه می‌شود.
  • شمارندهٔ چای در sessionStorage ذخیره می‌شود.

skills.html — مهارت‌ها

  • هر مهارت یک .skill با --lvl (درصد meter)، سال و تگ‌ها.
  • شمارندهٔ کنار هر دامنه در نویگیشن را دستی به‌روز کنید.
  • لینک‌های proof → به پروژه/مقاله اشاره می‌کنند؛ آن‌ها را با کارهای واقعی عوض کنید.

افزودن پروژهٔ جدید — ۵ قدم

  1. یک <article class="card work-card …" data-slug="…" data-cat="…"> در #mosaic بسازید (کپی از کارت موجود).
  2. کلاس اندازه: --xl (بزرگ)، --sm، --md، --wide.
  3. یک ردیف .index-row با همان data-slug/data-cat در نمای index اضافه کنید.
  4. ورودی PROJECTS[slug] را بنویسید.
  5. شمارندهٔ <sup> دکمه‌های فیلتر را به‌روز کنید.

عکس واقعی به‌جای موکاپ: داخل .work-media، .mock را با <img loading="lazy" width="…" height="…" style="width:100%;height:100%;object-fit:cover"> عوض کنید. .work-veil و .work-go را نگه دارید. مودال همان media را clone می‌کند، پس عکس هم منتقل می‌شود.

۱۲

سئو و متا

  • هر صفحه title، description، canonical، hreflang و OG/Twitter کامل دارد.
  • JSON-LD: Person / AboutPage / CollectionPage / Blog / BlogPosting / ContactPage.
  • post.html هنگام تغییر مقاله، متاها و canonical را زنده به‌روز می‌کند.
  • تصویر اشتراک: assets/og-cover.png در ابعاد ۱۲۰۰×۶۳۰ بسازید.
User-agent: *

برای ایندکس‌شدن تک‌تک مقالات، خروجی استاتیک بسازید (مثلاً post-frameworks-behind.html) یا رندر سمت سرور؛ محتوای داخل ?p= ممکن است کامل ایندکس نشود.

۱۳

دسترسی‌پذیری

  • skip-link، :focus-visible با حلقهٔ لهجه، و aria-current روی ناوبری.
  • مودال‌ها: role="dialog" + aria-modal + focus trap + بازگشت فوکوس + Esc.
  • شمارنده‌ها و توست‌ها: aria-live="polite".
  • دکمه‌های فیلتر/تگل: aria-pressed؛ آیکون‌ها: aria-label.
  • کنتراست: متن ریز لهجه‌ای از --accent-ink استفاده می‌کند نه --accent؛ متن روی دکمه تیره است تا AA پاس شود.
  • همهٔ انیمیشن‌ها با prefers-reduced-motion خاموش می‌شوند.

اگر رنگ لهجه را عوض کردید، حالت auto در استودیو، رنگ متن را طوری مشتق می‌کند که کنتراست حفظ شود.

۱۴

کارایی

  • بدون فریم‌ورک، بدون باندلر؛ هر صفحه فقط یک CSS مشترک + CSS خودش.
  • فونت‌ها: preconnect + display=swap. برای سرعت بیشتر می‌توانید self-host کنید.
  • انیمیشن‌ها فقط روی transform و opacity؛ اسکرول با rAF throttle و passive.
  • Observerها بعد از اولین تریگر unobserve می‌شوند.
  • موکاپ‌ها CSS/SVG هستند؛ اگر عکس واقعی گذاشتید: loading="lazy" + width/height + WebP/AVIF.
  • backdrop-filter و لایهٔ grain هزینهٔ GPU دارند؛ روی دستگاه ضعیف با استودیو blur و grain را کم کنید.
۱۵

امنیت و CSP

قالب inline <style> و <script> دارد. سیاست زیر با آن سازگار است:

default-src 'self';
script-src 'self' 'unsafe-inline';
style-src 'self' 'unsafe-inline' https://fonts.googleapis.com;
font-src 'self' https://fonts.gstatic.com;
img-src 'self' data:;
connect-src 'self';
form-action 'self';
base-uri 'self';
frame-ancestors 'none';
object-src 'none'

برای CSP سخت‌گیرانه: inlineها را به فایل منتقل کنید و از nonce یا hash استفاده کنید.

اتصال واقعی فرم تماس به PHP

<?php
declare(strict_types=1);
session_start();
header('Content-Type: application/json; charset=utf-8');

// ۱) فقط POST
if ($_SERVER['REQUEST_METHOD'] !== 'POST') { http_response_code(405); exit; }

// ۲) CSRF
$in = json_decode(file_get_contents('php://input'), true) ?: [];
if (!hash_equals($_SESSION['csrf'] ?? '', $in['csrf'] ?? '')) {
  http_response_code(419); echo json_encode(['error'=>'csrf']); exit;
}

// ۳) Honeypot
if (!empty($in['website'])) { echo json_encode(['ok'=>true]); exit; }

// ۴) Rate limit ساده
$now = time();
$_SESSION['hits'] = array_values(array_filter($_SESSION['hits'] ?? [], fn($t) => $now - $t < 600));
if (count($_SESSION['hits']) >= 3) { http_response_code(429); exit; }
$_SESSION['hits'][] = $now;

// ۵) اعتبارسنجی سمت سرور
$name  = trim($in['name']  ?? '');
$email = trim($in['email'] ?? '');
$msg   = trim($in['msg']   ?? '');
if (mb_strlen($name) < 2 || !filter_var($email, FILTER_VALIDATE_EMAIL) || mb_strlen($msg) < 30) {
  http_response_code(422); echo json_encode(['error'=>'validation']); exit;
}
// جلوگیری از header injection
if (preg_match('/[\r\n]/', $email . $name)) { http_response_code(422); exit; }

// ۶) ذخیره با prepared statement
$pdo = new PDO('mysql:host=localhost;dbname=hkf;charset=utf8mb4', 'user', 'pass',
  [PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION, PDO::ATTR_EMULATE_PREPARES => false]);
$ref = 'HKF-' . date('Y') . '-' . random_int(1000, 9999);
$pdo->prepare('INSERT INTO briefs (ref,name,email,services,budget,timeline,body,created_at)
               VALUES (?,?,?,?,?,?,?,NOW())')
    ->execute([$ref, $name, $email, implode(', ', $in['services'] ?? []),
               $in['budget'] ?? '', $in['time'] ?? '', $msg]);

// ۷) اطلاع‌رسانی (PHPMailer توصیه می‌شود)
$safeName = htmlspecialchars($name, ENT_QUOTES, 'UTF-8');
mail('hello@kazemifakhr.ir', "[$ref] Project brief",
     "$safeName <$email>\n\n$msg",
     "From: noreply@kazemifakhr.ir\r\nContent-Type: text/plain; charset=utf-8");

echo json_encode(['ok'=>true, 'ref'=>$ref]);
// در contact.html بلوک setTimeout ارسال را با این عوض کنید:
const res = await fetch('/api/brief.php', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  credentials: 'same-origin',
  body: JSON.stringify({
    csrf: CSRF_TOKEN,           // از سرور در صفحه تزریق شود
    website: '',                // honeypot — باید خالی بماند
    name: fName.value.trim(),
    email: fEmail.value.trim(),
    services, budget,
    time: TIME_LABELS[+fTime.value],
    msg: fMsg.value.trim()
  })
});
if (!res.ok) { showToast('ارسال ناموفق — دوباره تلاش کنید'); return; }
const { ref } = await res.json();
// سپس همان UI موفقیت موجود را با ref واقعی نشان دهید

چک‌لیست امنیتی

  • اعتبارسنجی سمت سرور علاوه بر کلاینت.
  • Prepared statement برای هر کوئری؛ htmlspecialchars هنگام نمایش.
  • CSRF token + honeypot + rate limit.
  • جلوگیری از header injection در ایمیل (حذف \r\n).
  • لینک‌های خارجی: rel="noopener" (در قالب رعایت شده).
  • HTTPS + HSTS؛ کوکی‌های نشست با HttpOnly; Secure; SameSite=Lax.

نسخهٔ فارسی / RTL

همین صفحه نمونهٔ زندهٔ RTL است — با همان global.css ساخته شده. برای ساخت fa/:

  1. صفحات را در پوشهٔ fa/ کپی کنید.
  2. <html lang="fa" dir="rtl">.
  3. فونت Vazirmatn را جای‌گزین Inter/Space Grotesk کنید.
  4. letter-spacing منفی تیترها را صفر و line-height را ≈۱٫۹ کنید.
  5. موارد جهت‌دار جدول زیر را اصلاح کنید.
  6. لینک‌های hreflang و منوی زبان دوطرفه هستند؛ فقط مسیرها را چک کنید.

افزودن صفحهٔ جدید

  1. یک صفحهٔ موجود را کپی کنید (مثلاً about.html).
  2. متاها، title، canonical و JSON-LD را عوض کنید.
  3. aria-current="page" را روی لینک جدید بگذارید.
  4. CSS اختصاصی داخل <style> را بازنویسی کنید.
  5. بخش مشترک JS را نگه دارید، بخش صفحه را عوض کنید.
  6. به ناوبری دسکتاپ، منوی موبایل و فوتر اضافه کنید.
  7. اسکلت زیر حداقلِ لازم است:
<!DOCTYPE html>
<html lang="en" dir="ltr" data-theme="light">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>…</title>
  <link rel="stylesheet" href="assets/css/global.css">
  <script>/* اسکریپت ضد-FOUC تم — بخش ۰۷ */</script>
  <style>/* CSS اختصاصی */</style>
</head>
<body>
  <a class="skip-link" href="#main">Skip to content</a>
  <!-- header + mobile menu مشترک -->
  <main id="main">
    <section class="section" id="top">
      <div class="container">
        <p class="kicker reveal">// new page</p>
        <h1 class="h2 reveal">…</h1>
      </div>
    </section>
  </main>
  <!-- footer مشترک + اسکریپت مشترک -->
</body></html>

پچ‌های پیشنهادی

۱) TOC خودکار برای همهٔ مقالات

در post.html مقالاتی که از <template> می‌آیند، تیترهای بدون id دارند و TOC خالی می‌ماند. این قطعه را بلافاصله بعد از ساخت article و قبل از ساخت TOC اضافه کنید:

// به هر h2 بدون id، شناسهٔ یکتا بده
var used = {};
$$('h2', article).forEach(function(h, i){
  if (h.id) return;
  var base = (h.textContent || 'section').trim().toLowerCase()
    .replace(/[^\w\u0600-\u06FF]+/g, '-').replace(/^-+|-+$/g, '') || ('s' + i);
  var id = base, n = 2;
  while (used[id] || d.getElementById(id)) id = base + '-' + (n++);
  used[id] = 1; h.id = id;
});
