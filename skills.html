// how engagements run

Four steps, no mystery.

You always know what ships Friday, and what it costs to change your mind.

STEP 01

Question

We write the mas’ala: the exact problem, its boundaries, and who benefits if it fails. No proposal before this page exists.

→ output: problem brief

STEP 02

Contract

Scope, interfaces, latency budget and price — signed before code. Changes are priced, not argued.

→ output: fixed scope + SLOs

STEP 03

Build

Weekly demos on a staging URL you can click. Tests and performance gates run beside every commit.

→ output: weekly shippable increments

STEP 04

Handover

Docs, runbooks, audit trail and a walkthrough recorded. You own the repo, the keys and the decisions.

→ output: ownership, transferred
